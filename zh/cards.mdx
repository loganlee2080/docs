**卡片**模块让您管理所有 Stable Mesh 虚拟 Mastercard——查看余额、控制消费并监控动态。

![卡片列表](https://4076010231-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgAL1jFwTHQPnvJRWEAtJ%2Fuploads%2Fgit-blob-c6e817887035ee77ae5ec210c7c05d2b8e25a731%2F02_cards_list.png?alt=media)

---

## 卡片列表

点击左侧导航栏的**卡片**，查看您的所有虚拟卡。列表包含以下信息：

| 列名 | 说明 |
| --- | --- |
| **别名** | 您为卡片设置的名称 |
| **卡号** | 卡片后四位 |
| **可用余额** | 卡片当前可消费的美元金额 |
| **状态** | `ACTIVE`（绿色）或 `FROZEN`（橙色） |

---

## 卡片详情面板

点击任意卡片行，右侧弹出详情面板。

![卡片详情](https://4076010231-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FgAL1jFwTHQPnvJRWEAtJ%2Fuploads%2Fgit-blob-c0380d3732a4c5ebb1b2416e9e17574766b951ae%2F04_card_detail.png?alt=media)

面板显示内容：

- **卡片图片** — 遮蔽部分卡号及网络标识（Mastercard）
- **操作按钮** — 查看信息、冻结/解冻、删除
- **可用余额** — 包含充值按钮
- **交易记录** — 可向下滚动查看完整消费日志

---

## 卡片操作

| 操作 | 说明 |
| --- | --- |
| [查看敏感信息](/zh/cards/sensitive-info) | 显示完整卡号、有效期和 CVV |
| [冻结 / 解冻](/zh/cards/freeze-unfreeze) | 即时锁定或恢复消费功能 |
| [充值](/zh/cards/top-up) | 从加密钱包转入资金 |
| [查看交易记录](/zh/cards/transactions) | 浏览卡片消费历史 |

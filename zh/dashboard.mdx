## 页面布局

左侧导航栏提供平台各功能的快速入口：

| 导航项 | 功能说明 |
| --- | --- |
| **首页** | 余额概览与最近交易记录 |
| **卡片** | 管理所有虚拟卡 |
| **个人资料** | 账户设置 |

---

## 仪表盘各模块

### 总余额

显示您加密钱包持有量与所有卡片余额的**合计金额**（以美元计）。

> 总余额 = 加密资产 + 所有卡片余额

### 加密资产

显示各支持稳定币的链上钱包余额：

- **USDT** — Tether USD
- **USDC** — USD Coin

这些是可充值到虚拟卡的可用资金。

### USD 卡片

所有虚拟卡的快速汇总，显示各卡当前可用余额。点击**查看全部**进入完整卡片页面，或点击任意卡片行打开详情面板。

### 最近交易

显示所有卡片的最新消费记录，包括商户名称、交易类型和金额。

## 快捷操作

| 按钮 | 功能 |
| --- | --- |
| **\+ 充值** | 向钱包添加加密货币 |
| **创建卡片** | 申请新的虚拟卡 |
| **SOL** 下拉菜单 | 切换充值网络 |
